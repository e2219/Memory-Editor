# 记忆编辑师 · Memory Editor

以「对话即改写记忆」为核心的中文文字推理游戏，支持手机浏览器和命令行。

三位自称伊莱朋友的人，请你通过文字会谈帮助他。他记得厨房里一条完整的橙皮，却想不起那个人的脸。你可以追问细节、安抚情绪，也可以向他提供一种新的解释。但你说的话，不一定只是问题。

**当前为可玩的 MVP，非医疗工具。** 代码负责记忆、数值、冲突与结局；DeepSeek 负责理解输入和扮演患者，不能直接修改状态。叙事仍可能不自然或解析失败。

> 源码已公开，许可证尚待作者选择，目前未附加开源许可证；公开可见不等于已授予修改、再分发或商用许可。剧情底稿也在源码里，想保留推理体验请先游玩，再阅读 `src/seed.ts`、`src/revelation.ts` 等文件。

## 如何游玩

1. 选择 **询问／共情／暗示**，输入一句自然语言。
2. 阅读伊莱的回应，对照「记录」里的已公开线索；记录不等于事实。
3. 自行选择阅读或忽略「邮件」。联系人来信随已公开信息与剧情进展送达。
4. 在「研判」记录疑点与解释。它不向剧情人物公开，也不显示答案正确率。
5. 点击「结案」提交治疗解释，或保留疑点、暂不定论。结局后自行决定是否逐字揭开完整背景。

### 三种干预

| 方式 | 用途 | 例子 |
| --- | --- | --- |
| 询问 | 中立核实已出现的细节 | 「削橙子的那双手有什么特征？」 |
| 共情 | 回应既有情绪，不替他指定事实 | 「想不起来也没关系，我们慢慢来。」 |
| 暗示 | 提供未经证实的身份、因果或解释 | 「也许是你的家人在给你准备水果。」 |

系统依据话语含义校验操作，不依据是否有问号。方式不匹配时可以切换或重写，回合不会直接提交。

### 状态与结束条件

- **信任**影响敏感追问和暗示接受度；低到危险线可能造成关系破裂。
- **稳定**影响记忆连贯性；失稳可能出现需复核的污染线索，严重时触发危机。
- **清晰**影响辨别能力；越低越容易接受暗示。
- 同一方式连续第三次起会疲劳。**询问的信任扣减延后到连续第六次**，前五次不扣信任，其他疲劳效果不变。换用共情或暗示会重置连续询问计数。
- 关系破裂与稳定崩溃各有一次共情挽救机会。
- 每局最多 **25 个治疗回合**。达到上限后仍可阅读资料、记录研判并结案，不能继续患者对话。
- 至少交流一次且没有未处理危机时，可以「暂不定论」结束。正式治疗解释需要达到后期条件；不保证随意输入一句结论就能触发理想结局。
- 阅读邮件、查看线索、私人研判不消耗治疗回合。结案有二次确认；关闭弹窗／按 Esc 可返回，已提交对话不能撤销。

## 快速开始：本机网页

需要 **Node.js 22.6 或更新版本**，建议使用受支持的 Node.js LTS。当前没有第三方 npm 依赖，不需要 `npm install` 或前端构建。

```bash
git clone https://github.com/e2219/Memory-Editor.git
cd Memory-Editor
npm test
npm run web
```

打开终端打印的地址，默认 <http://127.0.0.1:3210>。登录页选择以下一种方式。

### A. 玩家使用自己的 DeepSeek API Key（默认）

不需要在服务端设置代付 Key。在页面选择「使用我自己的 DeepSeek API Key」，填写 Key 并确认数据传输说明。

- 使用 [DeepSeek 开放平台](https://platform.deepseek.com/) 的 API 凭据，**不是网页版登录密码**，也不能使用网页版免费聊天额度。
- Key 通过本站后端调用固定的 DeepSeek 官方接口与 `deepseek-chat` 模型。
- Key 不写入游戏存档、LocalStorage 或 SessionStorage，只保留在服务内存中。闲置 30 分钟后失效并由清理任务释放；主动退出或服务停止也会释放。JavaScript 内存管理不保证物理内存立即清零。
- 服务重启或 Key 过期后，保留同一会话 Cookie，点击「凭据 / 退出」重新输入 Key，继续原局。
- 自带 Key 的请求失败时，**不会改用服务器持有人的 Key**。
- 本站运营者及终止 HTTPS 的代理／隧道服务在技术上能够接触提交的 Key。请仅在可信站点输入，最好使用独立低余额 Key；更私密的方式是自己部署。
- 格式通过后可进入游戏，首轮 API 调用才验证 Key 的实际可用性；不预先验证余额。

### B. 玩家使用邀请人的独立邀请码

由部署者配置自己的 Key 并私下发放邀请码。玩家只输入邀请码，不需要也不会拿到部署者的 Key。

邀请码是一项访问凭据：**同一个码会恢复同一局**，持码者可看到该局记录。请一人一码，不要发到公开群，也不要把它当作共享密码。即使临时网址变了，用同一码仍可恢复原局，不重置回合和额度。

### C. 不调用 API 的离线演示

```bash
npm run web -- --mock
```

输入终端打印的演示口令。此模式使用固定模板，仅适合检查界面和规则，**不代表在线对话质量**。在线失败不会自动伪装成 Mock。

## 邀请人：配置代付与邀请码

仅自带 Key 模式无需此步骤。在启动服务的同一终端设置环境变量，不要把真实 Key 写进代码或命令参数。

macOS / Linux 的 Bash、Zsh：

```bash
read -r -s DEEPSEEK_API_KEY
export DEEPSEEK_API_KEY
export SPONSOR_MAX_REQUESTS=600
npm run web
```

执行 `read` 后粘贴 Key 并按回车，输入不可见是正常现象。Windows 用户可通过终端环境变量或以下本地 `.env` 方式配置。

也可将 `.env.example` 复制成本机 `.env`，在编辑器内填入 Key，然后**显式加载**：

```bash
node --env-file=.env --experimental-strip-types src/web.ts
```

`npm run web` 不自动读取 `.env`。`.env` 已被 Git 忽略，请勿强制加入版本管理。

另开终端，在同一项目目录生成邀请码：

```bash
npm run invite -- create "朋友 A" 120 7
npm run invite -- list
npm run invite -- revoke <邀请码ID>
```

`create` 的参数依次为备注、上游 HTTP 请求上限、有效天数，默认 `120` 次和 `7` 天。明文邀请码仅在创建时显示一次，账本仅保存其哈希。`list` 显示 ID、备注、用量、上限和过期时间，不显示 Key 或邀请码。若自定义了存档目录，邀请码命令必须设置相同的 `PLAYTEST_DATA_DIR`。

### 两层限额

| 限制 | 默认值 | 作用 |
| --- | --- | --- |
| 每局治疗回合 | 25 | 游戏流程上限 |
| 每局回合请求尝试 | 60 | 包括模型失败、操作不匹配等尝试 |
| 每邀请码上游 HTTP 请求 | 120 | 分析、叙事、重写和重试均计数 |
| 所有邀请码累计上游请求 | 600 | `SPONSOR_MAX_REQUESTS`，0 关闭代付 |
| 同时处理中游戏回合 | 3 | 限制并发 |
| 浏览器会话名额 | 30 | 不是 30 人同时在线 |

额度**在请求 DeepSeek 前持久化预留**。请求失败也计数；服务重启、退出、换浏览器、重复输入同一码不会重置代付总用量。重放同一已成功提交的请求不会重复结算。撤销阻止后续上游请求，已经发出的请求可能仍完成并计费。

这里限制的是请求次数，**不是人民币金额**。输入长度、输出上限及重试次数受程序限制，但实际费用仍取决于 Token 与 DeepSeek 定价。请同时在供应商端控制余额／额度。不要删除、回滚或复制账本来清空用量；提高总限额需部署者主动调整环境变量并重启。

## 部署与异地测试

架构是 **Node.js 后端 + 静态 HTML/CSS/JS 前端**，不是仅上传静态文件就能玩的页面。GitHub 仓库存代码，**GitHub Pages 不能运行本项目的 Node 后端**。

- 默认只监听 `127.0.0.1`。异地访问需要 HTTPS 反向代理或临时隧道，只转发游戏端口，不要把项目目录当静态文件目录。
- 生产部署建议稳定域名、HTTPS、边缘限流及供应商消费限制；当前不是经过完整安全审计的公网服务。
- 3—5 人集中测试可临时用 `localhost.run` 等服务，但第三方会中转流量，免费域名可能变化、失效或在部分网络打不开。不要提交真实个人隐私。
- 电脑、Node 服务和隧道需持续运行。关闭页面不等于停止服务或撤销邀请码。
- 同一存档目录只运行**一个 Node 服务进程**。JSON 存档不支持多实例部署；多实例需要事务数据库与分布式会话／限流。
- 代理应保留正确的 Host、Origin，并设置 `X-Forwarded-Proto: https`。Cookie 不自动跨域复制；邀请码可恢复同一局，自带 Key 的匿名局暂不支持跨设备找回。

### 环境变量

| 名称 | 用途 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 邀请人代付 Key；不设置仍可使用玩家自己的 Key |
| `SPONSOR_MAX_REQUESTS` | 所有邀请码累计上游请求上限，默认 600，0 关闭 |
| `PLAYTEST_PORT` | 本机监听端口，默认 3210 |
| `PLAYTEST_DATA_DIR` | 专用存档目录，在线默认 `data/online`；服务与邀请码命令必须使用同一目录 |
| `PLAYTEST_CODE` | 仅 Mock 模式演示口令；在线不接受旧共享口令 |
| `DEEPSEEK_API_URL` | 仅命令行／诊断支持；网页服务刻意忽略，固定官方上游以保护凭据 |

## 安全边界：不是通用 API 代理

- 只提供游戏操作，没有 `/v1/chat/completions` 等通用转发路由。
- 字段白名单拒绝客户端自定义模型、上游 URL、`messages`、系统提示词及原始状态；模型上下文由服务端根据存档构建。
- Key 不进入模型提示词、普通 API 响应或存档；上游错误正文不会原样回显。
- 未公开记忆和未读邮件正文不会下发；完整背景仅在结局后主动请求。但源码公开意味着读源码者可看到剧情底稿，这不是 DRM。
- 有 HttpOnly / SameSite Cookie、同源检查、CSP、输入长度限制和服务端数值校验。**同源检查不是防脚本滥用的绝对屏障**，攻击者可以直接构造 HTTP 请求。
- 自然语言提示词攻击仍可能让模型偏离角色，不能保证完全杜绝。主要保障是后端规则、有限额度、可撤销邀请码和供应商预算，而非隐藏网址或前端代码。
- 反代页面不等于拿到 Key，但泄露的邀请码／会话仍可能被滥用。发现异常先撤销邀请码，必要时停止服务并更换供应商 Key。

## 存档、隐私与故障处理

- `data/online/`：在线会话 JSON 和 `invites.json` 额度账本；`data/mock/`：离线演示存档。不要提交 GitHub。
- “私人研判”仅指不向剧情人物公开，**服务器运营者可以读取**。输入会发送给 DeepSeek 参与游戏，请勿填写敏感医疗／身份信息。
- 浏览器只保存草稿、待确认请求等，不保存 Key；主动退出清除本机草稿。关闭网页不会立即清除服务内存 Key，需要等待闲置过期或主动退出。
- 自带 Key 模式保留 Cookie 才能恢复原局；清 Cookie、换设备、换域名或主动退出，目前没有账号找回功能。更新 Key 应用「凭据 / 退出 → 更新 Key」，不要为此退出。
- 没有实名验证、完整操作审计或管理员面板；邀请码备注只代表持码者，不是实名证明。
- 历史存档不会自动从磁盘删除，部署者应自行制定保留周期；备份同样要保护账本密钥、会谈和研判。
- 账本损坏或 `ledger.lock` 残留时，代付会停止而非绕过额度。先停止所有服务／邀请码命令并备份数据，确认无写入者后再处理锁目录或恢复一致备份；不要在运行中删锁。
- “名额已满”：默认 30 个会话，自带 Key 换浏览器开局会占新名额；同邀请码重复登录恢复同一局。
- 旧共享口令会话不自动获得代付资格；原存档保留，需要选择新登录方式。

## 命令行与测试

```bash
npm run play -- --mock              # 不产生 API 费用
npm run play                       # 使用终端 DEEPSEEK_API_KEY
npm run play -- --debug             # 调试输出可能含剧透，勿公开个人记录
npm run diagnose:deepseek           # 一次小额度连通性测试
npm test                           # 自动化测试，不调用真实 DeepSeek
```

命令：`/帮助`、`/规则`、`/线索`、`/建议`、`/邮件`、`/打开 编号`、`/忽略 编号`、`/研判 文本`（别名 `/研讨`）、`/笔记`、`/关注 编号`、`/提交结论`（别名 `/结案`）、`/暂不定论`。Esc 或 `/返回` 取消未提交输入。`--demo` 为三回合演示，不是完整流程。

测试覆盖确定性规则、状态危机、披露边界、结局、取消输入、存档隔离、额度持久化、重试计费、邀请码撤销、Key 隔离及禁止通用转发字段。浏览器布局与具体移动网络仍需真机验收。

## 项目结构

```text
src/
  engine.ts         确定性数值、冲突、阶段与结局
  turn.ts           分析 → 校验结算 → 叙事 → 披露校验 → 提交
  context.ts        从当前状态构造模型上下文
  deepseek.ts       DeepSeek JSON 接口与调用前额度预留
  credentials.ts    临时玩家 Key、邀请码与持久化代付预算
  invites.ts        本机邀请码创建、列出、撤销
  web-server.ts     HTTP 游戏接口、会话与存档
  web.ts / cli.ts   网页与命令行入口
  seed.ts           初始世界与记忆（含剧透）
  revelation.ts     结局后的完整背景（含剧透）
web/                手机优先界面、可选轻环境声
tests/              不耗 API 的回归测试
```

当前四类结局及变体保留原有判定；更自由的证据推理、主动联系委托人、更多分支与管理面板属于后续计划，不代表已经实现。
